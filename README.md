# 출고리스트 생성기

구글 시트 `출고가능리스트` 탭에서 선택한 출고 기간의 스타일을 읽어 중복 제거 후 엑셀 파일로 다운로드하는 Node.js 웹앱입니다.

웹페이지는 `요약` 탭을 먼저 보여주고, 원하는 주차 버튼을 누르면 해당 주차 기간으로 전환됩니다. `상세 리스트` 탭에서는 시작일~종료일 사이의 날짜별 스타일 목록을 확인할 수 있습니다. 상세 리스트는 출고일자/구분/아이템을 여러 개 선택해 필터링할 수 있고, 스타일 코드 검색도 지원합니다. 아이템은 `아이템코드(대분류)` 형식으로 표시합니다. 출고일자, 구분, 스타일은 오름차순/내림차순 정렬을 지원합니다. 차수를 누르면 같은 스타일의 차수별 출고 예정일, 입고예정일, 수량을 확인할 수 있습니다.

한 주 기준은 화요일부터 다음 주 월요일까지이며, 요약표에는 화/수/목/금/월만 표시합니다. 엑셀 파일은 첫 번째 시트 `출고요약`, 두 번째 시트 `출고리스트`로 생성됩니다. 상세 시트에는 `출고일자`가 첫 번째 컬럼으로 들어갑니다. 요약은 화/수/목 16,000장, 금/월 10,000장을 기준으로 캐파를 넘는 날짜를 빨간색으로 표시하고, 공휴일은 어두운 음영으로 표시합니다.

공휴일은 한국 공휴일 캘린더를 불러와 판단합니다. 기간 안에 포함된 토/일/공휴일은 출고리스트에서 제외됩니다.

상품명에 `RE KAG55SS`처럼 원 스타일 번호가 들어간 리오더 상품은 현재 스타일 번호가 달라도 같은 상품으로 묶습니다. 스타일 비교는 앞의 `MIW` 또는 `MIA`를 제외한 나머지 코드가 같은지를 기준으로 합니다.

## 로컬 실행

1. `run-web.bat`을 더블클릭합니다.
2. 브라우저가 열리면 비밀번호를 입력합니다.
3. 시작일을 선택하고 `엑셀 다운로드`를 누릅니다. 종료일은 기본적으로 시작일과 같게 맞춰지며, 여러 날짜가 필요할 때만 종료일을 따로 바꿉니다.

환경변수 `SHIPPING_LIST_PASSWORD`가 없으면 로컬 기본 비밀번호는 `1234`입니다.

## 서버 실행

```powershell
$env:SHIPPING_LIST_PASSWORD="팀에서 사용할 비밀번호"
node server.mjs
```

호스팅 서비스에서는 `PORT`와 `SHIPPING_LIST_PASSWORD` 환경변수를 설정하면 됩니다. 생성된 엑셀 파일은 서버에 저장하지 않고 다운로드 응답으로만 만들어집니다.

## CLI 실행

```powershell
node generate-shipping-list.mjs 2026-05-19
```

CLI는 `outputs/출고리스트_YYYY-MM-DD.xlsx` 파일을 생성합니다.
